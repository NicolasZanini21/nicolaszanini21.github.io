01 Cómo trabajo con IA

No uso la IA para que escriba y yo copie sin mirar. La uso como parte del flujo, pero reviso cada resultado antes de darlo por bueno. Un ejemplo real: en Edith, la integración con Gemini dejó de responder de un día para el otro. Diagnostiqué que el modelo que estaba referenciando había quedado desactualizado, corregí la referencia y verifiqué respuesta por respuesta hasta confirmar que el asistente volvía a funcionar de forma estable. El criterio para detectar la falla y confirmar la solución fue mío, la IA aceleró la escritura del código. 

# edith/bridge/gemini_client.py — fragmento simplificado
MODEL_FALLBACK = "gemini-1.5-flash-latest"  # referencia vigente tras el diagnóstico

def ask_gemini(prompt, context):
    try:
        response = model.generate_content(prompt, context=context)
    except ModelDeprecatedError:
        # el modelo original quedó deprecado: logueo, reintento con el vigente
        log.warning("modelo desactualizado, reintentando con %s", MODEL_FALLBACK)
        response = model.generate_content(prompt, context=context, model=MODEL_FALLBACK)
    return verify_before_return(response)  # nunca devuelvo sin verificar
